Šta ovaj projekat pokazuje?

Projekat prikazuje semantički HTML, CSS stilizaciju, Bootstrap grid, responsive dizajn, lokalne slike, JavaScript funkcije, event listenere, filtere, sortiranje, favorite, modal i localStorage.

  • Sortiranje podataka
  • Favoriti i localStorage
  • Poređenje sportaša
